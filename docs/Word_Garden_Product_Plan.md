# Word Garden 功能与升级规划文档

生成日期：2026-07-05

## 1. 项目定位

Word Garden 是一个英语单词、例句、短文朗读和 AI 学习内容生成工具。当前形态是本地 Web App，通过 `server.js` 提供本地服务，用户可以在浏览器中学习单词、听朗读、生成 AI 例句、生成睡前故事和学习小纸片。

目标用户可以是学生、家长、英语学习者，也可以扩展到学校场景。后续可以升级为手机 App、硬件墨水屏学习卡和更大的英汉词库系统。

## 2. 当前已实现功能

### 2.1 单词学习

- 按领域学习：日常、旅行、食物、校园、商务、儿童等。
- 单词卡展示：英文单词、音标、中文释义、英文例句、中文翻译。
- 学习难度选择：按学习角色和难度滑块调整推荐词。
- 智能推荐：根据词频、难度、兴趣领域、复习状态排序。
- 复习优先：需要复习的单词可以优先出现。
- 学习行为记录：已掌握、100% 学会、需要复习、收藏、跳过。
- 已掌握库：已学会的单词可隐藏，也可恢复继续学习。
- 学习日历：记录每天新增、复习和学习情况。

### 2.2 例句功能

- 每个单词默认有 3 条例句。
- AI 可为当前单词生成新的真实场景例句。
- AI 例句不是覆盖原例句，而是追加到例句分页中。
- 每 3 条例句为一页，可以左右切换。
- 播放时只朗读当前例句页。
- AI 例句会保存到本地状态中，下次打开同一个单词仍可查看。
- 全局保存最近 100 组 AI 例句，避免无限占用本地存储。

### 2.3 朗读与 TTS

- 支持本地离线音频播放。
- 支持跨平台本地 Piper TTS。
- 支持 OpenRouter/OpenAI 云端声音。
- 短文朗读支持多级回退：
  1. 先尝试当前选择的云声音。
  2. 云声音失败或 Key 不可用时，自动尝试本地 TTS。
  3. 本地 TTS 失败时，退回浏览器朗读。
- AI 例句页没有本地离线音频时，会通过 `/api/tts` 生成音频，不再误播不存在的 wav 文件。
- 已新增 Piper TTS 支持方案：
  - 配置了 Piper 时，优先使用 Piper 本地神经 TTS。
  - Piper 未配置或不可用时返回明确配置错误。

### 2.4 短文朗读和难词学习

- 用户可以粘贴英文短文。
- 系统自动高亮高难词。
- 用户可以手动点击词语，把它加入学习库。
- 支持整篇短文朗读。
- 支持整篇 AI 翻译。
- AI 翻译可提取难词，辅助后续学习。

### 2.5 AI 睡前故事

- 可以基于当前学习词生成双语睡前故事。
- 可选择年龄段、英语等级和故事主题。
- 生成成功后保存到本地。
- 下次打开页面会自动显示最近一篇故事。
- 保存最近 20 篇故事。
- 故事历史列表可点击查看旧故事。

### 2.6 学习小纸片

- 当前支持生成学习小纸片。
- 支持围绕当前单词生成相近词或同主题词。
- 支持 AI 生成扩展词卡。
- 支持打印预览。

## 3. 已完成的重要升级

### 3.1 AI 例句分页保存

原来 AI 例句会替换原来的 3 条例句。现在改为：

- 原始 3 条保留为第 1 页。
- 每次 AI 生成追加 3 条。
- 每 3 条一页。
- 用户切换到哪页，播放时就朗读哪页。
- 生成结果保存到本地，下次仍可查看。

### 3.2 AI 睡前故事保存

原来故事只显示在页面上，刷新后会丢失。现在改为：

- 生成成功后保存完整故事内容。
- 保存标题、英文、中文、年龄段、难度、主题、目标词、Token、生成时间。
- 下次打开自动显示最近一篇。
- 可从历史列表查看旧故事。

### 3.3 TTS 灵活回退

原来如果云端 Key 不可用，短文朗读可能直接失败或只退到浏览器朗读。现在改为：

- 云 TTS 失败后自动尝试本地 TTS。
- 本地 TTS 失败后再尝试浏览器朗读。
- 新增 Piper 本地神经 TTS 接入点。

## 4. 词库扩展建议

### 4.1 推荐数据源

优先考虑免费、开源、许可证清楚的数据源：

- ECDICT：英汉词典底座，适合导入单词、音标、中文释义。
- Tatoeba：英中句对，适合补充大量双语例句。
- NGSL：高频基础词表，适合入门和常用词学习。
- CEFR-J / English Profile 类词表：适合给单词标注 A1-C2 难度。
- WordNet：适合同义词、词义关系和主题扩展。

### 4.2 建议导入流程

1. 下载 ECDICT CSV。
2. 写导入脚本，把 CSV 转成 `word-bank.json` 结构。
3. 用 Tatoeba 给单词匹配例句。
4. 用 NGSL / CEFR 词表补充难度等级。
5. 用规则或 AI 给单词打领域标签。
6. 每个词至少保留 3 条例句，更多例句进入分页。

## 5. Piper TTS 升级方案

### 5.1 为什么选择 Piper

Piper 是轻量、开源、本地运行的神经 TTS，适合离线学习工具。相比云 TTS，它不依赖 Key，也不需要联网。

### 5.2 推荐工作流

1. 下载适用于当前操作系统的 Piper 可执行文件。
2. 下载英文 voice model，例如 `en_US-lessac-medium.onnx`。
3. 放到项目目录：

```text
tools/piper/piper
voices/en_US-lessac-medium.onnx
voices/en_US-lessac-medium.onnx.json
```

4. 配置 `.env`：

```text
PIPER_BIN=/absolute/path/to/piper
PIPER_VOICE_EN=/absolute/path/to/en_US-lessac-medium.onnx
```

5. 重启 `server.js`。

### 5.3 TTS 优先级建议

完整策略：

1. 用户选择云声音时，先用 OpenRouter/OpenAI。
2. 云失败时，尝试 Piper。
3. Piper 失败时，服务端返回可操作错误；页面上的浏览器原生朗读仍可作为交互朗读方案。

## 6. 墨水屏学生卡升级构想

### 6.1 产品想法

设计一个可以挂在身上的墨水屏学习卡。用户在手机 App 或网站中生成学习内容，通过蓝牙同步到墨水屏卡片。卡片可以显示多页单词、例句、复习题和故事片段，学生随时随地翻页学习。

### 6.2 硬件建议

第一版建议使用：

- ESP32 主控。
- 2.13 或 2.9 寸黑白墨水屏。
- 300-500 mAh 电池。
- USB-C 充电。
- 2 个实体键：上一页、下一页。
- 1 个长按操作：进入蓝牙同步模式。
- 外壳做成学生证卡套大小，带挂绳孔。

可选开发板：

- LILYGO T5 ePaper。
- Waveshare ESP32 e-Paper Driver Board + 2.9 寸 e-paper。
- Adafruit MagTag 类似方案。

### 6.3 软件架构

分三层：

1. 网站或手机 App：
   - 生成内容。
   - 排版成墨水屏页面。
   - 导出 bitmap 或压缩后的 1-bit 页面数据。

2. 蓝牙传输层：
   - 使用 BLE GATT 服务。
   - 按页分包传输。
   - 每页传输完成后校验 CRC。

3. 墨水屏固件：
   - 接收页面。
   - 存储多页到 flash。
   - 按键翻页。
   - 空闲休眠。
   - 断电后画面保持。

### 6.4 墨水屏页面模板

建议先支持这些模板：

- 单词页：大单词、音标、中文释义。
- 例句页：英文例句、中文翻译。
- AI 例句页：每页 1-2 条。
- 复习页：先显示英文，按键后显示中文。
- 睡前故事页：故事拆成短段落。
- 小测页：选择题和答案页。

### 6.5 数据格式建议

不要传 HTML。建议 App 端先渲染成固定分辨率页面，再传给硬件。

示例格式：

```text
magic: WGEP
version: 1
screen: 296x128
pageCount: 12
pageIndex: 0
format: 1bit-rle
payload: compressed bitmap bytes
crc32: ...
```

### 6.6 MVP 路线

第一阶段先不做硬件蓝牙，先在网站里做：

- 墨水屏卡片预览。
- 尺寸选择：296x128、212x104、400x300。
- 多页黑白预览。
- 导出 `epaper-pack.json`。

第二阶段：

- 用开发板通过 USB 串口接收页面包。
- 固件显示多页内容。
- 实现按键翻页。

第三阶段：

- 增加 BLE 传输。
- 手机 App 或 Web Bluetooth 连接。
- 支持无线更新卡片内容。

第四阶段：

- 做低功耗优化。
- 做外壳。
- 做批量学生卡管理。
